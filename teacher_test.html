Help & System FAQ
✕

How does P2P Attendance function?

When local host hotspots are active, student clients authenticate directly to the teacher device using WebRTC Data Channels, allowing off-grid tracking.

What is a Random Ring event?

It is a random prompt dispatched during lectures. Students have a strict timer window to verify via their local camera or location. If failed or rejected, face bypasses can be evaluated by the teacher.

Manual overrides vs All Day overrides?

Manual overrides let you correct student attendance errors. Current period marking overrides only the active period, whereas 'All Day' marks the student present for all lectures of that specific calendar date.
